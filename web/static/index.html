    Meet the team
    
      
    Three roles in code. Only Captain Q learns; Robo's brain (Qwen) stays frozen.
    
      
    
        
    
          
    
          
    Robo · the Solver
    
          
    Qwen2.5-0.5B-Instruct writes a step-by-step solution and puts the answer in a box. Try 1 is careful (greedy); later tries are a bit creative (sampled).
    
        
    
        
    
          
    
          
    Hoot · the Verifier
    
          
    Never sees the answer key. Checks every written calculation with a safe calculator, and can ask for a tiny Python program to compute the answer another way.
    
        
    
        
    
          
    
          
    Captain Q · the Coordinator
    
          
    Learned with Q-learning which move pays off: accept, try again, or double-check. Each move costs a little, a right answer earns +1, a wrong one −1.
